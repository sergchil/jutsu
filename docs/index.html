jutsu

pstack by Lauren Tan (poteto), ported to Claude Code inside T3 Code.

One command, /jutsu, turns on poteto mode. Each task goes to the matching pstack playbook, and the work is proven before it is called done.

Install
git clone https://github.com/sergchil/jutsu.git
cd jutsu && ./install.sh
View on GitHub What is pstack?

How it works

  1. Type $jutsu and your task in a T3 thread. In plain Claude Code, type /jutsu and your task.

  2. jutsu picks the matching pstack playbook, such as bug fix, feature, refactor, getting a PR to merge, or an overnight run. Then it follows the playbook's steps.

  3. It proves the work on the real thing, such as tests, the browser, or a simulator, before it says done. Poteto mode stays on for the whole thread until you type /jutsu off.

Made for T3 Code

In T3, jutsu uses T3's own tools: parallel threads in their own worktrees, PR watching, schedules, the browser, and simulators.

Use it

Needs
Claude Code 2.1.292 or newer, and Python 3.9 or newer for the installer. T3's thread, PR, and schedule tools need T3 Code nightly from 2026-10-03. Without T3, jutsu runs in plain Claude Code.
Start
$jutsu fix the flaky login test in a T3 thread
Stop
/jutsu off
Models
/jutsu:setup-pstack picks the model and effort for each role
Update
git pull in the jutsu folder
Remove
./uninstall.sh removes everything jutsu added. Your repos are not touched.

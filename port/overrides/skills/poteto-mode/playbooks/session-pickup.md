### Session pickup

**You own the resume point. Read the prior trail, don't redo it.**

1. Locate the prior trail. A resume note from Pause safely under `.p3/<slug>/` ([the runtime's Store](../references/runtime.md#store)), a T3 thread, a Claude transcript under the active workspace's project directory ([the runtime's History](../references/runtime.md#history) names both. Do not glob across `${CLAUDE_CONFIG_DIR:-~/.claude}/projects/*/` or read other projects' threads, that crosses workspace boundaries and reads private chats from unrelated projects), or a pushed branch. Read the metadata overview and last messages first, skipping `isMeta` and local-command records, then scan back for the decision points. Parse a long transcript in a subagent and keep the reduced timeline in the main thread (the **principle-guard-the-context-window** skill, `{{p3}}/principles/principle-guard-the-context-window.md`).
2. Reconstruct operational state. The branch and worktree, what already landed (`git log`, `git diff` against the base), the open todos (the prior task list, or its `.audit/<slug>.todo.md` file per [the runtime's Todo list](../references/runtime.md#todo-list)), the decisions made. If the resume note lists paused schedules or unwatched PRs, re-enable each schedule (`update_scheduled_task` with `enabled: true`) and re-watch each PR before you continue. If the prior agent may still run, confirm it stopped (its T3 thread status, or the agent list, where `completed` means notified, not exited) and check `git status` before you take its work. The prior trail is authoritative input. Resist the bias to re-derive it.
3. Diff done vs pending. Compare what shipped against what was planned, name the resume point, do not re-run the prior repro or redo completed work. A "let me verify from scratch" pass means you're treating the trail as untrustworthy when it's authoritative.
4. Route the remaining work to the matching playbook and pick the verdict: continue the execution, ship a finished recommendation, ratify or override a prior conclusion, or postmortem a failed run. The pickup playbook ends here. The routed playbook owns the rest.
5. Verify the inherited claims against the original goal on the real artifact (the **principle-prove-it-works** skill, `{{p3}}/principles/principle-prove-it-works.md`). A passing prior self-report is not the proof.

**Reply:** where the prior agent stopped, what you inherited vs redid (ideally nothing redone), the resume point, and the outcome.
